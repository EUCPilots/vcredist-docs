# Unterstützte Plattformen

## Windows-Versionen

VcRedist ist für Windows-Systeme vorgesehen. Die Installationsprogramme der Redistributables unterstützen die von Microsoft für jedes Paket angegebenen Windows-Versionen. VcRedist wurde auf aktuellen Windows-Client- und Serverversionen getestet, einschließlich x64 und ARM64.

## PowerShell-Editionen

VcRedist 5 erfordert PowerShell 5.1 oder höher. Version 5 wird mit Windows PowerShell 5.1 und PowerShell 7 auf x64- und ARM64-Windows getestet.

Die lokale Inventarisierung, Installation und Deinstallation erfordern Windows. Die Intune-Integration erfordert Windows PowerShell 5.1 und das Modul `IntuneWin32App`. Die Configuration Manager- und MDT-Integrationen erfordern die jeweiligen Windows-Verwaltungskomponenten. MDT-Befehle sind veraltet und werden nach bestem Bemühen unterstützt.
