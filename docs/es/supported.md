# Plataformas compatibles

## Versiones de Windows

VcRedist está diseñado para sistemas Windows. Los instaladores de Redistributables son compatibles con las versiones de Windows especificadas por Microsoft para cada paquete. VcRedist se ha probado en versiones actuales de cliente y servidor de Windows, incluidas x64 y ARM64.

## Ediciones de PowerShell

VcRedist 5 requiere PowerShell 5.1 o posterior. La versión 5 se prueba con Windows PowerShell 5.1 y PowerShell 7 en Windows x64 y ARM64.

La detección local, la instalación y la desinstalación requieren Windows. La integración con Intune requiere Windows PowerShell 5.1 y el módulo `IntuneWin32App`. Las integraciones con Configuration Manager y MDT requieren sus respectivos componentes de administración de Windows; los comandos de MDT están en desuso y se admiten según el mejor esfuerzo.
