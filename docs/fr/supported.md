# Plateformes prises en charge

## Versions de Windows

VcRedist est destiné aux systèmes Windows. Les programmes d'installation des redistribuables prennent en charge les versions de Windows spécifiées par Microsoft pour chaque package. VcRedist a été testé sur les versions actuelles de Windows client et serveur, notamment x64 et ARM64.

## Éditions de PowerShell

VcRedist 5 nécessite PowerShell 5.1 ou une version ultérieure. La version 5 est testée avec Windows PowerShell 5.1 et PowerShell 7 sur Windows x64 et ARM64.

L'inventaire, l'installation et la désinstallation locales nécessitent Windows. L'intégration à Intune nécessite Windows PowerShell 5.1 et le module `IntuneWin32App`. Les intégrations à Configuration Manager et MDT nécessitent leurs composants de gestion Windows respectifs ; les commandes MDT sont obsolètes et ne sont prises en charge que dans la mesure du possible.
