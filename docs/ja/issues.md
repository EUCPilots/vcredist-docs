# 既知の問題

::: info
サポートされる言語は **英語 (米国)** のみです。このモジュールは Visual C++ 再頒布可能パッケージの `en-US` バージョンのみをダウンロードします。
:::

::: info
`Get-VcList` は、マニフェスト内の VcRedist バージョンと、ダウンロードしたファイルの `ProductVersion` プロパティとの一致を試みます。`2005` および `2008` の VcRedist インストーラーでは Product Version がインストール済み VcRedist と一致しないため、インストーラーが正しいバージョンであってもファイルが再ダウンロードされます。
:::

::: info
Visual C++ 再頒布可能パッケージ 2012 Update 5 は入手可能です。この更新プログラムは Visual Studio のダウンロード サイトにありますが、ダウンロードにはサインインが必要です。[Visual Studio の公開ダウンロード ページ](https://visualstudio.microsoft.com/vs/older-downloads/)では引き続き Update 4 が提供されているため、VcRedist が提供するのはこのバージョンです。
:::

::: info
Visual C++ 再頒布可能パッケージ 2008 `9.0.30729.7523` は入手可能ですが、[非公開の修正プログラム](https://support.microsoft.com/en-us/help/2834565/fix-visual-c-2008-mfc-application-that-was-created-by-using-visual-stu)としてのみ提供され、Microsoft から一般向けにダウンロードすることはできません。
:::

::: info
次の Visual C++ 再頒布可能パッケージはダウンロードできなくなりましたが、VcRedist マニフェストには引き続き含まれています。

* Visual C++ 2005 Redistributable Package、バージョン `8.0.50727.42`
* Visual C++ 2005 SP1 Redistributable Package、バージョン `8.0.56336`
* Visual C++ 2008 SP1 Redistributable Package、バージョン `9.0.30729`
:::
