# MDT での再頒布可能パッケージ バンドルの作成

::: warning
VcRedist 5 の MDT コマンドは非推奨であり、今後のメジャー リリースで削除される可能性があります。サポートはベストエフォートです。
:::

Visual C++ 再頒布可能パッケージを MDT 展開共有にインポートすると、タスク シーケンスに追加できる個別のアプリケーションとして利用できます。選択を簡素化するため、これらをアプリケーション バンドルにまとめることができます。バンドルは MDT 共有内のアプリケーションであり、それ自体はアプリケーションをインストールしませんが、依存関係としてほかのアプリケーションを含みます。そのため、タスク シーケンスの 1 つのアクションで、特定の順序に従って一連のアプリケーションをインストールできます。

バンドルの Version プロパティには現在の日付が設定されるため、バンドルの作成日または最終更新日を簡単に確認できます。

## パラメーター

### 必須パラメーター

* `MdtPath` - MDT 展開共有のローカル パスまたはネットワーク パス

### オプションのパラメーター

* `AppFolder` - Visual C++ 再頒布可能パッケージをサブフォルダーにインポートします。既定値は `VcRedists` です。
* `MdtDrive` - MDT 展開共有に割り当てるドライブ文字です。省略可能で、既定値は `DS001` です。
* `Publisher` - Visual C++ 再頒布可能パッケージのバンドルに割り当てる発行元です。省略可能で、既定値は `Microsoft` です。
* `BundleName` - Visual C++ 再頒布可能パッケージのバンドルに割り当てる短い名前です。省略可能で、既定値は `Visual C++ Redistributables` です。
* `Language` - 既定値は `en-US` です。

## 例

対象の展開共有にバンドルを作成するには、`New-VcMdtBundle` を実行します。この関数は既定のアプリケーション フォルダー (VcRedists) にある Visual C++ 再頒布可能パッケージを検索し、古い順に各アプリケーションを依存関係として登録したバンドルを作成します。

```powershell
New-VcMdtBundle -MdtPath \\server\deployment
```
