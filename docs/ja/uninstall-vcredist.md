# 再頒布可能パッケージのアンインストール

ローカル コンピューター上の Visual C++ 再頒布可能パッケージをアンインストールするには、`Uninstall-VcRedist` を使用します。この関数には、アンインストール対象の Visual C++ 再頒布可能パッケージのリリースとアーキテクチャを指定します。指定したパッケージのサイレント アンインストールを試みます。

`Uninstall-VcRedist` の実行には、Windows 上で管理者特権に昇格した PowerShell セッションが必要です。PowerShell の高影響操作向け確認機能を使用します。明示的に確認を求めるには `-Confirm`、プロンプトを抑制するには `-Confirm:$false` を使用します。

## パラメーター

### 必須パラメーター

ありません。フィルターを指定しない場合、`2022` を含むすべてのリリースと x86 および x64 アーキテクチャのインストール済み再頒布可能パッケージが選択されます。ARM64 は `-Architecture ARM64` で指定できますが、既定では選択されません。既定ではアンインストール前に確認を求めます。

### オプションのパラメーター

* `Confirm` - PowerShell の確認プロンプトを制御します。`-Confirm:$false` でプロンプトを抑制します。
* `Release` - アンインストールする再頒布可能パッケージのリリース (またはバージョン) を指定します (例: `14`、`2019`、`2012` など)。
* `Architecture` - アンインストールするアーキテクチャを `x86`、`x64`、`ARM64` から指定します。既定値は x86 と x64 です。
* `VcList` - `Get-VcList` または `Get-InstalledVcRedist` からパイプライン経由でエントリを受け取り、アンインストールする特定の再頒布可能パッケージを選択します。

## 例

次のコマンドは、ローカル システムに現在インストールされているすべての Visual C++ 再頒布可能パッケージをアンインストールします。

```powershell
Uninstall-VcRedist -Confirm
```

次のコマンドは、インストール済みの Visual C++ 再頒布可能パッケージのうち `2008` リリースをアンインストールします。

```powershell
Uninstall-VcRedist -Release 2008
```

インベントリから選択したインストール済みエントリをアンインストールします。

```powershell
Get-InstalledVcRedist | Where-Object Release -eq "14" | Uninstall-VcRedist
```

このコマンドは、選択した項目ごとに状態オブジェクトを返します。削除に成功した場合の `State` は `Uninstalled`、製品がすでに存在しない場合は `Not installed`、アンインストーラーを実行できない場合や予期しない終了コードが返された場合は `Failed` です。手動モードで `-Release` と `-Architecture` の両方を明示的に指定した場合、該当する組み合わせが見つからない場合も `Not installed` として返されます。
