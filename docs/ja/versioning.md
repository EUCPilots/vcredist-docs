# VcRedist のバージョン管理について

VcRedist は `major.minor.patch[-prerelease]` 形式のバージョン管理を使用します。バージョン 5 では破壊的変更が導入されました。`5.0.4-beta5` などのベータ リリースは、プレリリース ビルドを示します。

## メジャー リリース

メジャー リリースでは、通常、破壊的変更が導入されます。VcRedist モジュールを使用するスクリプトが動作しなくなる可能性があります。

## マイナー リリース

マイナー リリースでは、通常、新しいパブリック関数などの機能が追加されます。VcRedist モジュールを使用するスクリプトに影響しない想定ですが、テストは常に推奨されます。

## パッチ リリース

パッチ リリースでは、バグ修正とメンテナンス更新が提供されます。プレリリースのサフィックスは、安定版リリースではないことを示します。
