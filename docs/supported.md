# Supported platforms

## Windows versions

VcRedist is intended for Windows systems. The Redistributable installers support the Windows versions specified by Microsoft for each package. VcRedist has been tested on current Windows client and server releases, including x64 and ARM64.

## PowerShell editions

VcRedist 5 requires PowerShell 5.1 or later. The v5 release is tested with Windows PowerShell 5.1 and PowerShell 7 on x64 and ARM64 Windows.

Local inventory, installation and uninstallation require Windows. Intune integration requires Windows PowerShell 5.1 and the `IntuneWin32App` module. Configuration Manager and MDT integrations require their respective Windows management components; MDT commands are deprecated and supported on a best-effort basis.
